The Workspace Editor: The Canvas Everything Else Connects To

SARVARC Blog

Every module in SARVARC Workspace eventually feeds into one place: the Editor. Tables from Data Arrangement, charts from Diagrams & Graphs, and whatever Refine Report pulls together all land on the same canvas. This is a look at what that canvas actually does once your content is on it.

Crop, restyle, translate, sign, resize, and export, across PDFs, Word docs, and Excel files alike, all without leaving the page.

Opening Any File, From Any Module or Any Format

The upload box accepts PDF, DOCX, XLSX, XLS, XLSM, XLSB, ODS, CSV, and TSV files, and you can load more than one at once. A DOCX file doesn't open as a flat picture: every paragraph becomes a movable text box, every table stays editable with rows and columns you can add or remove, and every image becomes a placed image, with headings, bold and italic, colors, links, lists, alignment, and page size all carried over.

A spreadsheet works the same way. Each sheet becomes one or more pages holding an editable table, wide sheets switch to landscape automatically, and long sheets continue across pages with the header row repeated. All of that conversion happens on your device, nothing is uploaded to do it.

Older formats aren't supported yet: a .doc, .rtf, or .odt file gets rejected with a message asking you to save it as .docx first.

Combined with content pushed in from Data Arrangement or Diagrams & Graphs, a single page on this canvas might have a table that started as a CSV, a chart built in the charting module, and text typed directly into the Editor, all sitting together as one document. Nothing about the workflow changes based on where a piece of content came from.

Crop: Cleaning Up a Page Before It Joins the Rest

Crop matters more once you understand the canvas is assembling content from multiple sources. A scanned page with uneven margins next to a clean chart from Diagrams & Graphs looks mismatched. Drag the crop box over the page, preview it at any zoom level, then Apply to lock it in or Cancel to leave it untouched. It's a small tool, but it's what keeps a document built from a few different sources looking like it came from one.

Dragging a crop box over a page. Nothing is re-rendered until Apply is clicked, so the original stays untouched if you cancel.

Style Specific Text: Restyling One Word or Phrase Across the Entire Document

A document built from a few different sources often needs the same term treated the same way everywhere it shows up: a client's name in bold, a product name in the brand color, a deadline underlined wherever it's mentioned. Doing that by hand means opening every page, selecting each instance, and applying the format one at a time. Style Specific Text does it in one pass. Type the word or phrase in the search box, choose bold, italic, a font, a color, or any combination, and hit Apply. Every matching occurrence across the whole document gets restyled at once.

There's no separate whole word toggle to configure. A single word is matched as a whole word automatically, so styling "cat" won't also catch "category". A phrase with spaces or punctuation is matched exactly as typed instead, since word boundaries don't apply to a sentence. The search runs live as you type, highlighting every match on the page before anything is actually applied, so you can see what's about to change first.

The Style Specific Text panel, always visible in the right-hand panel and ready to search the whole document.

It also reaches further than just the page you have open. Text pulled from an uploaded PDF, text typed directly into the Editor as a placed text box, and text sitting on a page nobody has opened yet are all searched the same way, so nothing typed from another module or added straight onto a blank canvas gets missed.

That matters most on longer documents: a report with a client name repeated across a dozen pages, or a contract where one defined term appears in several clauses. Instead of hunting through each page to keep the formatting consistent, one search and one click handles every instance, and the whole change lands on the same undo history as everything else on the canvas, so it can be reversed with a single Ctrl+Z if it goes further than intended.

Translate: Carrying the Whole Assembled Document Into Another Language

Translate converts just the current page into another language, and Translate All runs the same translation across every page in one action. Both are opt in and only send the specific text being translated, nothing else. Languages include Spanish, French, German, Portuguese, Arabic, Chinese, and Japanese.

Because it runs on whatever's on the page, it doesn't matter whether that text originated in the Editor or arrived from another module. It translates the finished page.

Signature: The Last Step Before a Document Leaves the Canvas

A document assembled from a table, a chart, and some written context is usually headed somewhere: a proposal, a contract, a report that needs sign-off. The Signature tool handles that final step without leaving the canvas. Draw a signature by hand, type it in a signature-style font, or upload an image of an actual signature, then place it anywhere on the page like any other element.

Drawing a signature by hand, with Smart Smoothing straightening shaky lines into a clean signature.

Custom Page Sizes: The Canvas Isn't Just for Documents

The Editor isn't locked to document dimensions either. Alongside A4, A3, A5, and Legal, a Custom option opens up:

Inserting a new page with a chosen size, background, and optional starting content, right from the same dialog.

  • Square (1080×1080 px) for an Instagram post
  • Story (9:16, 1080×1920 px) for Instagram, Facebook, or WhatsApp stories
  • US Letter and Tabloid for print
  • A fully custom width and height in millimeters, inches, or pixels, with a swap button and a one-click square button

A chart built in Diagrams & Graphs doesn't have to end up on an A4 report page. It can just as easily land on an Instagram square, since it's the same placed element on the same canvas either way.

The Utilities That Do the Actual Editing Work

With the page open and content in place, here's what handles the day-to-day editing:

Annotate covers Highlight, Draw, Eraser, and a full shape library (Arrow, Box, Circle, Line, Double Arrow, Rounded Box, Triangle, Diamond, Pentagon, Star, Hexagon), plus Redact for blacking out sensitive numbers or clauses. A Border/Frame tool adds a page border, applied to one page or the whole document.

OCR scans a scanned or flattened page's text so it becomes editable, and Extract Text pulls the readable text off a page or the whole document for reuse elsewhere.

Extract Text pulls the readable text off a page, ready to copy or download as a .txt file.

Insert covers Image upload, a Gallery of previously extracted images, Stock Photo search, and Table insertion with an Excel-style grid picker or one of four smart presets: Data Table, Invoice Items, Comparison, and Simple List, useful when you need a quick table without pulling one in from Data Arrangement.

Image Adjustments give Brightness, Contrast, and Saturation sliders with a live preview, and Canvas Color sets the page background as a Solid color, a Gradient, or an uploaded Image.

The page strip on the left shows every page as a live thumbnail: drag to reorder, hover between pages to insert a new one, duplicate or delete with one click, plus Rotate Left and Rotate Right per page.

Queue handles a stack of files at once, in any mix of formats, with Auto continue moving you to the next file automatically once you finish the current one.

A batch queue with three files loaded. Auto continue moves to the next one the moment the current file is finished.

Export finishes the job with five formats: PDF Document with optional password protection, Excel Spreadsheet as a real .xlsx workbook, Word Document with editable .docx tables, CSV for raw table data, and Image as one PNG per page, zipped automatically if more than one page is selected. Each export includes a page range picker and a live thumbnail preview.

Choosing a format in the Export dialog. Each option previews what that page will actually contain before you export it.

Exporting to Word Document. A detected logo or letterhead can be embedded as is, or extracted with its background removed.

Exporting to PDF with password protection on. If the password is ever lost, Password Recovery in PDF Tools can help you get back into the file.

A few finishing tools round it out: Find in document search with next/previous navigation, a Compare view for before and after, full Undo, Redo, Clear, and Revert history, and a PDF Tools dropdown with Merge PDF, Remove Password, and Password Recovery.

Frequently Asked Questions

Can the Editor open a Word or Excel file, not just a PDF?

Yes. The upload box accepts PDF, DOCX, XLSX, XLS, XLSM, XLSB, ODS, CSV, and TSV files, and every format lands on the same canvas with the same tools available, whether the file was opened directly or pushed in from another module like Data Arrangement or Diagrams & Graphs.

Can I crop a page without losing quality?

Yes. The Crop tool lets you drag a crop box directly on the canvas at any zoom level, preview exactly what will be kept, and then either apply the crop or cancel and leave the page unchanged. Nothing is re-rendered until the crop is applied, so there's no quality loss in the process.

Can I style the same word or phrase everywhere it appears in a document, without editing each page by hand?

Yes. Style Specific Text searches the whole document at once, including pages you haven't opened yet and text typed directly into the Editor, and applies bold, italic, a font, and a color to every matching occurrence in a single pass. A single word is matched as a whole word automatically, and a phrase is matched exactly as typed.

How do I translate a page or an entire document?

Use Translate to convert just the current page into another language, or Translate All to run the same translation across every page in one action. Both are opt in, only send the specific text being translated, and support languages including Spanish, French, German, Arabic, Chinese, and Japanese, regardless of whether that text was typed in the Editor or arrived from another module.

Can I sign a document without printing it?

Yes. The Signature tool supports drawing a signature by hand, typing it in a signature-style font, or uploading a photo of an actual signature, which can then be placed and resized anywhere on the page like any other element.

Can I create a page sized for Instagram, a YouTube thumbnail, or a LinkedIn banner?

Yes. Built-in Square (1080×1080 px) and Story (9:16, 1080×1920 px) presets cover Instagram, Facebook, and WhatsApp posts and stories, and a fully custom width and height field in millimeters, inches, or pixels covers any other platform's exact spec, including a YouTube thumbnail or a LinkedIn banner.

What formats can I export a finished document to?

Five: PDF Document with optional password protection, Excel Spreadsheet as a real .xlsx workbook, Word Document with editable .docx tables, CSV for raw table data, and Image as one PNG per page, automatically zipped if more than one page is exported.

What if I forget the password on a PDF I protected?

The PDF Tools dropdown includes Password Recovery for exactly that situation, alongside Merge PDF and Remove Password. It's still worth keeping the password somewhere safe when you export with protection on, but a lost password no longer has to mean a locked file.

What does the Queue feature do?

Queue lets you load several files at once, in any mix of supported formats, and work through them one after another. Turning on Auto continue moves you automatically to the next file in the queue once you finish the current one, so you're not re-uploading files individually.

Does content pushed in from Data Arrangement or Diagrams & Graphs behave differently than content added directly in the Editor?

No. A table pushed in from Data Arrangement or a chart pushed in from Diagrams & Graphs lands on the canvas as a normal, editable element, so it can be cropped, moved, resized, or included in translation and export exactly like anything typed or inserted directly in the Editor.

The Bottom Line

Every module in SARVARC Workspace eventually points here: one canvas where whatever you built elsewhere becomes a finished, exportable document. That's not a small convenience. It's the difference between juggling five separate tools and working from one.
